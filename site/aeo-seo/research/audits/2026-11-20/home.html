What are AEO-SEO skills?

A skill is a folder with a SKILL.md file that teaches your AI agent one job, step by step. Install it once and your agent knows when to use it.

These skills treat SEO and AEO (answer engine optimization) as one job. The same page has to rank in Google and still make sense when ChatGPT lifts one paragraph out of it. So every page is written answer-first, backed by real search data, sourced facts and quotes from real people.

  1. 01

    Install the skills

    One command adds them to Claude Code, Codex, Cursor or any agent that reads SKILL.md. Then connect OpenSEO for search data.

  2. 02

    Build your site profile

    aeo-seo-setup reads your repo and live site, asks you the rest, and writes an aeo-seo/ folder: your domain, product, competitors and decisions.

  3. 03

    Ask for the work

    “Audit my site.” “Write a comparison page for us vs. X.” Your agent picks the right skill, does the research and stops for your approval.

FAQ

What is AEO (answer engine optimization)?+

AEO is the work of getting your content quoted in AI answers from ChatGPT, Perplexity, Claude and Google AI Overviews. Answer engines pull a single passage that answers the question, so AEO means writing sections that each answer one question clearly, citing sources and making your site easy for AI crawlers to read.

What's the difference between AEO and SEO?+

SEO gets a page ranked in Google's search results. AEO gets a passage from that page quoted in an AI-generated answer. They overlap heavily: AI engines mostly draw on pages that are indexed and trusted. These skills treat them as one job and write every page answer-first so it can do both.

How do I get my website cited by ChatGPT and Perplexity?+

Make sure AI crawlers can reach your pages, then publish pages that answer the exact questions your buyers ask, with the answer in the first sentence of each section, real numbers, named sources and quotes from real people. The aeo-seo-technical-audit skill checks the crawl side; the page skills handle the writing.

How do I show up in Google AI Overviews?+

Google builds AI Overviews from pages it already indexes and ranks, so the basics come first: a crawlable, indexed site and pages that rank for the query. Then write each section to answer one question directly. There's no separate switch to opt in, and no tool can guarantee a spot.

Can Claude Code or Codex do SEO?+

Yes, with the right skills and data. On their own, coding agents guess at keywords and invent numbers. These skills give them a step-by-step method and connect them to real Search Console and keyword data through OpenSEO, so they can audit a site, plan topics and ship pages you approve.

What are agent skills?+

Agent skills are folders with a SKILL.md file that teach an AI agent how to do one job. The agent reads each skill's short description and loads the full instructions only when a task needs them. Claude Code, Codex, Cursor and other agents support the format.

How do I install the AEO-SEO skills?+

Run npx skills add kingscrosslabs/aeo-seo-skills and pick the skills you want, or copy the folders into your agent's skills folder (for Claude Code, .claude/skills/). Then connect OpenSEO and run aeo-seo-setup to build your site profile.

Do I need a paid SEO tool to use these skills?+

You need an OpenSEO account. The skills use it for Search Console data, keyword volume and live search results, and they stop rather than guess a number if it isn't connected. Paid lookups use OpenSEO credits, and every result is cached so you never pay for the same data twice.

Will AI-written content hurt my Google rankings?+

Google's guidance is that it rewards helpful content however it's made, and penalizes mass-produced pages written to game rankings. These skills write one page at a time, from real research and first-hand experience, and wait for your approval before anything ships.

Are the AEO-SEO skills free?+

Yes. They're open source under the MIT licence. You pay only for your AI agent and any OpenSEO credits you use.
